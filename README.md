# Digital Health Record Management System (DHRMS)

A comprehensive healthcare management system built with Flutter and Node.js for managing health records, appointments, and healthcare services across different user roles.

## 🏥 System Overview

The DHRMS platform serves multiple healthcare stakeholders:
- **Patients**: Access personal health records, book appointments, emergency SOS
- **Hospital Staff**: Manage patient records, prescriptions, and hospital operations  
- **Regional Health Officers (RHO)**: Monitor regional health trends and statistics
- **State Health Officers (SHO)**: Oversee state-wide health metrics and staff management
- **WHO Officials**: Global health oversight and policy management

## 🚀 Quick Start

### Prerequisites
- Flutter SDK (latest stable)
- Node.js 16+ and npm
- MongoDB (local or Atlas)

### Installation
```bash
# Clone the repository
git clone <repository-url>
cd myhealth

# Install Flutter dependencies
flutter pub get

# Install backend dependencies
cd backend
npm install

# Start the development servers
npm run dev        # Backend on port 3000
flutter run        # Frontend on device/emulator
```
